# 🌱 Agro Forte — Futuro Sustentável

Site institucional moderno desenvolvido com **HTML, CSS e JavaScript**, com foco no tema:

> **“Agro Forte: Futuro Sustentável”**  
> Equilíbrio entre produção agrícola e preservação ambiental.

O projeto apresenta uma interface profissional, responsiva e visualmente inspirada no agronegócio sustentável, destacando inovação, produtividade e respeito ao meio ambiente.

# ⚙️ Como Executar

## 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/agro-forte.git
```

---

## 2. Acesse a pasta do projeto

```bash
cd agro-forte
```

---

## 3. Abra o arquivo `index.html`

Basta abrir o arquivo no navegador:

```bash
index.html
```

Ou utilize a extensão **Live Server** no VS Code.
